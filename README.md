## Core Learning Objectives

The documentation in this repository focuses on building a deep, fundamental understanding of:

* **Architectural Foundations:** Binary logic, compiler vs. interpreter translation, and memory hierarchy (Stack vs. Heap).
* **Language Semantics:** Data types, memory capacities, ASCII encoding, and operator mechanics.
* **Control Flow Mastery:** Complex decision-making (`if-else`, `switch`) and robust iteration (`for`, `while`, `do-while`).
* **Data Structures & Algorithms:** 1D/2D arrays, matrix operations, nested loops, and pattern generation with time/space complexity analysis.

## Day-wise Contents

### [Day 1: Foundations of C and Computer Architecture](C_Programming_PDP_Day1_Notes.pdf)
* Introduction to computer languages & why binary is used.
* Language translation categories (Compiler / Interpreter / Hybrid).
* How a computer works (CPU, ALU, Memory hierarchy).
* Historical context (Ken Thompson & Dennis Ritchie).
* Coding styles (Structural vs Monolithic).
* Data types, sizes, ranges & ASCII encoding.
* Structure of a C program & Preprocessor directives.
* Operators (Arithmetic, Relational, Logical, Pre/Post-Increment).
* Basic Input / Output and Escape sequences.
* Day 1 practice programs.

### [Day 2: Control Flow, Conditionals and Loops](C_Programming_PDP_Day2_Notes.pdf)
* Conditional statements & crucial rules of `if`.
* Classic decision programs (Odd/Even, Leap Year, Greatest of three, etc.).
* Introduction to loops (`for`, `while`, `do-while`).
* The **Fetch-and-Delete** pattern (digit processing mastery).
* Additional important loop programs (Count digits, Sum of digits, Reverse a number).
* Lab programs practiced on the system.

### [Day 3: Arrays and Nested Loop Patterns](C_Programming_PDP_Day3_Notes.pdf)
* **1D Arrays:** Contiguous memory layout, indexing from 0, sum, average, maximum, and minimum.
* **2D Arrays:** Matrix input/output, sum of elements, and matrix transpose.
* **Nested Loops:** Execution flow, complexity analysis, and inner-loop mechanics.
* **Pattern Printing:** The 4 base patterns, Floyd's Triangle, combination patterns, and trace tables.
* **Edge Cases:** Common pitfalls, array bounds, and practice challenges.

## Compilation Guide

All programs in these notes are compiled using **GCC**. To run them locally:

```bash
# Compile the C file with warnings enabled
gcc -Wall filename.c -o output

# Execute the compiled program
./output
```
